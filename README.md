# Project 3: Around The U.S.

**Intro**

This project's design focuses on responsive design to display elements nicely on popular screen sizes. This webpage is for displaying scenic locations around the US. The user can update his profile name, about and profile picture. The user can add and delete scenic location posts. The scenic locations and user profile info is stored in a TripleTen api. The link to this project: https://gitsheils.github.io/se_project_aroundtheus/. A short demo is available (https://drive.google.com/file/d/1JPO0NlWDh7uhMRMXe2hnD0qXGeQ7axMD/view?usp=sharing).
